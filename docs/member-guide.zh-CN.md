# 成员指南

## 进入 DSH 与使用平台应用中心

用管理员创建的成员账户登录。平台会打开 `/app/<spaceId>/` 下属于你的 DSH 空间，项目、会话与工作区文件留在这个空间。通过原生模型选择器选用已启用的共享模型。进不了 DSH 时，可打开 `/recovery`。

分组开放「平台应用中心」时，可从 DSH 侧栏打开。「插件」「技能」和「MCP 服务」页签显示你可以使用的资源。应用中心跟随 DSH 语言，登录、恢复和管理后台使用当前浏览器的平台语言。

- 在已发布插件的行中选择「安装」，即可按行内标识取得原生副本或共享密钥自选。平台管控插件只读加载。原生副本可在原生插件设置中管理。在 DSH 独立安装的同名副本仍由原生插件页管理。
- 支持主动更新的平台交付副本会显示「有更新」或「有内容更新」和目标版本。选择「更新插件」，等待结果，按提示重启 DSH。库内更新不会自动更新成员副本。服务设置报错时先看状态，再按页面提示选择「应用服务设置」「重试服务初始化」或重启实例。可继续使用个人设置。
- 自选需要的技能或技能包。分组预装的技能只读。保存在个人技能目录的同名技能可以优先生效，应用中心会显示覆盖提示。
- 启用需要的 MCP 服务。分组要求启用的服务在授权有效期间保持开启。可关闭可选服务或移除自选项。MCP 工具在下次 agent 请求时刷新。平台同名服务优先时，原有个人设置仍会保留。

管理员开启语音输入后，启动或重启实例以取得设置。通过 HTTPS 远程访问或用 localhost 打开平台，并授权浏览器使用麦克风。平台联网搜索由管理员配置专用搜索密钥，该设置不使用共享模型密钥。

## 从本地归档安装原生插件

此流程需要管理员为你的分组开放终端和原生插件安装。若插件发布了兼容的 `.tgz`，而成员实例无法直接下载，请用自己的浏览器下载归档，保留原文件名，并核对发布方提供的 SHA-256。在自己的成员实例打开一个对话，通过编辑器添加归档附件。看到附件卡片后，把对话保留为草稿。

在成员终端获取已校验归档的路径。将下例中的文件名和 SHA-256 替换为实际值。

```sh
filename='your-plugin.tgz'
sha256='the-full-published-sha256'
prefix=$(printf '%.2s' "$sha256")
printf '%s\n' "$HOME/.dsh/attachments/v1/files/$prefix/$sha256/$filename"
```

成员实例没有已安装的同名副本时，从 DSH 侧栏打开「插件 → 添加插件」，将上述路径填入包地址，安装并启用。如 DSH 提示重启，重启实例后从侧栏打开插件。请在成员家目录保留已上传的归档，以便 DSH 继续使用本地安装来源。

## 远程打开 billion-context 原生面板

从「插件 → 添加插件」安装并启用 `billion-context`。如 DSH 提示重启，重启实例后在登录的 Phalanx 成员空间打开「设置 → bili」。面板服务监听在成员实例内部的回环地址。要让远程浏览器从同一个成员空间访问面板，请在个人配置中启用插件中继。

在成员终端编辑插件实际读取的配置。默认路径是 `~/.config/billion-context/billion-context.json`。若设置了 `XDG_CONFIG_HOME`，默认使用其下的 `billion-context/billion-context.json`。`BILI_CONFIG_FILE` 可指定文件路径，也可指定配置目录下的 `<名称>.json` 对应的名称。将 `security.adminRelay` 设为 `true`，保留其他设置。首次创建配置时可使用下列 JSON。

```json
{
  "security": {
    "adminRelay": true
  }
}
```

刷新成员页面，再打开「设置 → bili」查看压缩总览和会话。对话完成首次模型请求后，打开该对话的「上下文」。DSH 可能将该入口放在「更多会话视图」中。中继默认关闭。启用后，你可以从自己已登录的 Phalanx 成员空间访问完整面板，包括配置和凭据管理。

## 在此浏览器中切换账户

管理员在 DSH 侧栏头像账户菜单第一项看到「前往管理后台」，点击后在新标签页打开当前部署的 `/admin` 管理首页，DSH 页面保留。普通成员不显示该项。角色变化后刷新 DSH 页面更新菜单；后台始终按当前权限检查访问。

在 DSH 侧栏账户菜单或管理侧栏账户区选择「切换账户」。即使 DSH 无法启动，
部署地址的 `/recovery` 恢复页也会列出账户。选择可切换账户后，进入该账户的默认入口：
管理员进入管理界面，成员进入自己的 DSH。

- 「添加账户」打开登录页。输入该账户的用户名和口令登录一次后，此浏览器便会记住它。
  取消或登录失败保留当前账户。最多记住十个账户；满额时须先移除一个再添加，
  登录已有条目则更新该条目。
- 「移除」只让此浏览器忘记该条目，不会删除平台账户。可用条目的移除操作在行内更多菜单中；
  不可用条目直接显示「移除」，且不能选择切换。
- 「退出登录」只退出当前浏览器登录，保留条目并显示「需要重新登录」。登录页提供其他可切换账户，
  「使用其他账户」打开登录表单。「退出所有账户」同时清空已记住的列表和当前浏览器登录。

每次登录仍有效十二小时，切换不会延长会话。会话过期或被撤销后须重新输入口令；
停用或删除的账户显示为不可用。删除后用同名重建的账户不会接续旧条目。
列表只属于此浏览器，不会跨设备同步。

同一浏览器只有一个当前账户。切换后，其他打开的标签页显示阻挡操作的账户变更提示，
并断开原有实时连接；点击「前往」进入当前账户。不同标签页不能同时以不同账户操作。

**切换账户会直接清空 DSH 的浏览器本地存储，不弹确认。** 未发送的消息、回答 agent 提问时写到一半的内容、
自定义快捷键、侧栏布局、会话手动排序、编辑器和 shell 偏好都会丢失。
运行中的任务、agent 的提问和已保存的对话仍在账户实例中，切回来后可继续。
平台的「跟随系统」「浅色」「深色」外观偏好在切换后保留；此浏览器偏好与 DSH 主题相互独立。

## 下载产物

产物卡片和文档预览工具栏提供**下载**操作。浏览器保存路径下当前的原文件，包含无法预览的格式；Office 文件不会被转换后的预览 PDF 替代。中文文件名保持可识别。旧聊天中的引用跟随当前文件，不保存历史快照。

下载要求成员仍处于登录状态且会话有效。文件必须位于该成员的私有 HOME 或会话工作区，并通过原生文件权限检查。文件不存在或不可读时显示局部错误。较大文件分块传输；读取期间文件变更会使浏览器下载失败，请在写入完成后刷新重试。

## HTML 文件交互预览

HTML 和 HTM 文件打开时默认允许脚本交互，不受 **Show coding view** 开关影响。按钮、本地表单事件和 DOM 更新在隔离预览中执行；重新打开或重新读取文件会重置内存中的状态。

文件预览支持自包含文档：脚本不能读取平台页面或其登录凭据。资源加载及 API 请求受内容安全策略限制，但不保证阻止所有网络导航。不保证持久存储、任意外部资源可用或应用代码自身正确。需要服务端的应用应启动 HTTP 服务；打开文件本身不提供应用数据保存或服务托管。

## Office 预览字体

用户实例镜像随附 Debian Bookworm 的 Noto CJK（`1:20220127+repack1-1`）、Liberation 2（`2.1.5-1`）、Carlito（`20220224-1`）和 Caladea（`20200211-1`）。这些字体使用 SIL Open Font License 1.1，版权及许可说明保留在镜像内的 `/usr/share/doc/<package>/copyright`。官方 Office 转换器读取系统字体目录，并保留其默认字体替代规则。文档指定的字体缺失时，原生预览仍会显示提示；替代字体可能改变排版。

预览不会改写 Office 原文件。镜像升级后重启实例会创建新的转换器代次，重新打开已有文件时使用新字体，不复用旧转换器缓存的 PDF。不提供字体上传或字体管理页面。电子表格预览保留 DSH 的原生表格渲染器。

## 成员自配技能 Key

个人文件备份可能包含个人密钥、令牌和插件设置。将导出的文件或备份保存在只有你授权的人能访问的位置。插件自行保存的密钥不会自动进入平台数据库加密。

请在终端中将第三方 Key 写入自己空间的私有文件，权限设为 `0600`，并放在 DSH 配置重置范围之外。不要将真实 Key 粘贴到对话或共享技能包。例如，在 `~/.config/my-skill/secrets.env` 中保存 `EXAMPLE_API_KEY='your-personal-key'`。成员脚本能够读取这个私有文件。

DSH 不会自动把父环境中名称带 `KEY` 的变量传给 bash 工具；只保存 `.env` 或 DSH 凭据也不够。**每次 DSH bash 调用内**都要先加载私有文件，再进入加载技能时返回的资源目录执行脚本：

```sh
set -a
. "$HOME/.config/my-skill/secrets.env"
set +a
cd /path/returned/when/loading/the/skill
python3 scripts/example.py
```

请按技能要求替换变量名、资源路径和参数。管理员启用[平台代执行](skill-execution.zh-CN.md)后，配置的命令可使用平台凭据，成员无需另配个人副本。

## 成员登出与恢复

受保护平台插件在 DSH 侧栏账户菜单提供「Log out」「Restart instance」和「更多恢复选项」。登出只清除当前浏览器平台登录，已接受的任务继续执行。重启前须确认中断任务；成功后通过「Return to DSH」回到同一空间，配置、用户插件、聊天和文件保留。

即使 DSH 启动失败，有效成员凭据仍可登录平台并直接进入恢复页。DSH 无法加载时直接访问部署地址的 `/recovery`，仍可登出、重启并查看失败或成功反馈。也可从账户菜单的「更多恢复选项」进入同一恢复页。在「重置 DSH 环境」区块确认任务中断、配置与自行安装的插件会被重置后执行；项目、聊天记录和其他个人文件保留。成员每 10 分钟最多发起一次，失败尝试及平台重启后仍计算冷却时间；管理员不受限。如需找回旧配置，请联系管理员。平台始终使用当前登录身份决定目标。受保护的平台插件及管控或共享凭据只读插件不能通过普通插件管理停用或卸载，成员原生副本仍可管理。手动终端和自行添加原生插件依分组设置开放。
