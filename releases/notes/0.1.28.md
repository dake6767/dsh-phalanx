# 0.1.28

## English

### Switch accounts in one browser

Remember up to ten accounts and switch from the DSH account menu, management
sidebar, recovery page or login page. Available sessions need no password again;
switching keeps their original twelve-hour expiry. Add or remove entries, sign
out of the current account, or sign out of all remembered accounts. Disabled or
deleted accounts are unavailable and can be removed from the browser list.

One browser has one current account. Other tabs show an account-change notice
and close their old live connections. Running tasks and saved conversations
remain in their account's instance.

### Browser storage and appearance

Switching clears DSH's local browser storage immediately, without confirmation.
Unsent messages, unfinished answers, shortcuts, sidebar layout, manual conversation
ordering, and editor and shell preferences are lost. Agent questions and running
tasks remain available when switching back. Platform appearance now survives in
a browser cookie, with existing preferences migrated on page load.

See the [account-switching guide](../../docs/install.md#switching-accounts-in-this-browser)
for the available actions and session rules.

## 简体中文

### 在同一浏览器中切换账户

最多记住十个账户，可从 DSH 账户菜单、管理侧栏、恢复页或登录页切换。
会话有效时无需再次输入口令；切换保留原有十二小时有效期。
可添加或移除条目、退出当前账户，或退出所有已记住的账户。
停用或删除的账户显示为不可用，可从浏览器列表移除。

同一浏览器只有一个当前账户。其他标签页显示账户变更提示并关闭原有实时连接。
运行中的任务和已保存的对话仍在各自的账户实例中。

### 浏览器存储与外观

切换会直接清空 DSH 的浏览器本地存储，不弹确认。
未发送的消息、未写完的回答、快捷键、侧栏布局、会话手动排序、编辑器和 shell 偏好会丢失。
agent 的提问和运行任务保留，切回来后可继续。平台外观改存浏览器 cookie，
页面加载时迁移已有偏好，切换后仍保留。

操作及会话规则见[切换账户指引](../../docs/install.zh-CN.md#在此浏览器中切换账户)。
