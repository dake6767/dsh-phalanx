# 0.1.19

## English

DSH is pinned to `dsh-v0.2.1-rc.2`. Members can enable its built-in DeepSeek
Search/Fetch API without entering a key: the platform gateway uses an enabled
DeepSeek shared-model credential. Search/Fetch is off by default. The upstream
API Key control remains visible; leave it empty. This version does not record
or bill Search/Fetch usage.

Shared model rows now expose **Supports images**. Known vision models such as
`deepseek-flash` default to enabled; existing rows without a declaration receive
the same known-model default. The declaration applies to image uploads,
`read_image` and subagent image input.

The **Suite catalog** loads a signed online directory instead of shipping entries
inside the platform. Catalog additions and corrections can be published without
a platform release. See [suite operation](../../docs/skill-execution.md#suite-catalog)
for its default address, custom service configuration, rejection reasons and
offline behavior. Suite definitions contain declarative data and refer to
platform adapters; preparation no longer patches upstream MiniMax files.

### Upgrade from 0.1.18

Upgrade from formal 0.1.18 using the normal verified update path. The updater
performs the declared DSH runtime transition and restores the old version if
activation fails before commit. Existing 0.1.18 suite records are not migrated;
use the online catalog to update them to declarative entries. Other behavior of
those old suite records is not guaranteed. The MCP catalog remains bundled.
Usage records are not included in 0.1.19.

## 简体中文

DSH 固定到 `dsh-v0.2.1-rc.2`。成员可开启其内置 DeepSeek Search/Fetch API，
无需填写 key；平台网关使用已启用的 DeepSeek 共享模型凭据。Search/Fetch 默认关闭。
上游 API Key 控件仍然可见，请保持空白。本版本不记录 Search/Fetch 用量。

共享模型行新增**支持图片**开关。`deepseek-flash` 等已知识图模型默认打开；
缺少输入类型声明的已有模型按同一已知模型表补齐。图片上传、`read_image`
和子代理图片输入均遵守该声明。

**套件广场**改为在线读取签名目录，平台不再内置条目。新增或修正目录无需发布
平台版本。默认地址、自定义服务配置、拒绝原因及离线行为见
[套件操作说明](../../docs/skill-execution.zh-CN.md#套件广场)。套件定义只包含
声明式数据，并引用平台适配器；准备过程不再修改上游 MiniMax 文件。

### 从 0.1.18 升级

从正式 0.1.18 按常规校验升级流程更新。升级器执行声明的 DSH 运行时过渡，
提交前激活失败会恢复旧版。0.1.18 的套件记录不做格式迁移；可在在线广场中
更新为声明式条目，不承诺旧套件记录的其他行为。MCP 广场继续内置。
0.1.19 尚无使用记录页。
