# 0.1.24

## English

### Skills and plugins

The suite catalog is now the skill catalog under Skills. Plugins have their own
catalog under Plugins. Entries install their declared skills, plugins and shared
runtime dependencies together; administrators can detach an entry to manage its
items manually. The separate dependency-install entry point has been removed.
The previous `/admin/suites` address redirects to the skill catalog.

Shared runtime dependencies now support pinned Python libraries and resource-only
trees. Plugin access configuration can reference an authorized dependency with
`{dependency:<name>}`. Member mounts stay read-only, and dependency updates take
effect when an instance restarts.

The PPT Master catalog entry supports editable presentation generation, local
narration and image search. Administrators can configure an image or cloud
narration provider, or skip those fields. Platform credentials stay outside member
instances. Catalog skill imports have larger, bounded limits; ordinary imports
keep their existing limits. The OnlyOffice entry prepares shared core SDK resources before
members open documents, with member-local downloads for other assets.

PyMuPDF and OnlyOffice include AGPL components. They are downloaded from their
upstreams during deployment; consult each catalog entry's license information.

### Upgrade preparation

The release acceptance policy now lists blocking checks only. The updater shipped
with v0.1.23 rejects this policy. Download the new installer and update only the
updater first:

```sh
curl -fsSLo install.sh https://raw.githubusercontent.com/dake6767/dsh-phalanx/v0.1.24/install.sh
sudo bash install.sh --upgrade bootstrap --version v0.1.24 --output json
```

The platform keeps running. After the command reports `updater-ready`, return to
System update, check again and apply the release. Finish or recover an existing
prepared or interrupted operation before bootstrapping.

## 简体中文

### 技能与插件

套件广场更名为技能广场，入口移至技能页；插件页新增插件广场。条目统一引入声明的
技能、插件与共享运行依赖；管理员可脱离条目后手动管理这些项目。单独安装依赖的
入口已取消，旧 `/admin/suites` 地址重定向到技能广场。

共享运行依赖支持锁定版本的 Python 库与纯资源目录。插件接入配置可通过
`{dependency:<name>}` 引用已授权依赖；成员挂载保持只读，实例重启后切换新版本。

PPT Master 广场条目支持生成可编辑演示文稿、本地旁白与图库搜索。管理员可配置
生图或云端旁白后端，也可跳过；平台凭据不进入成员实例。广场技能导入有更大的
有界限额，普通导入保留原有限额。OnlyOffice 条目在成员打开文档前准备共享 SDK 核心资源，
其他资源继续下载到成员自己的缓存。

PyMuPDF 与 OnlyOffice 含 AGPL 组件，部署时从上游下载；许可信息见各广场条目。

### 升级准备

发布验收策略现在只列阻塞检查项。v0.1.23 随附的升级执行器会拒绝这一策略。
请重新下载新版安装脚本，先只更新升级执行器：

```sh
curl -fsSLo install.sh https://raw.githubusercontent.com/dake6767/dsh-phalanx/v0.1.24/install.sh
sudo bash install.sh --upgrade bootstrap --version v0.1.24 --output json
```

平台保持运行。命令返回 `updater-ready` 后，回到系统升级页，重新检查并应用升级。
已有准备完成或中断的升级操作须先完成或恢复，再执行 bootstrap。
