# 0.1.6

## English

- Fix adding shared model providers and model rows over HTTP when the browser does not expose `crypto.randomUUID`. Draft rows now use local identifiers; saved model identities are unchanged.
- Verify provider creation, independent model editing, deletion and saving against the packaged platform in an actual insecure browser context.

Upgrade from formal 0.1.5 through **System settings → Check for updates**. Applying the update restarts services and interrupts running tasks after confirmation. Accounts, stable user spaces, shared model configuration and preferences are retained. Account schema, DSH revision, environment epoch and upgrade protocol are unchanged.

Verification completed: [candidate acceptance](https://github.com/dake6767/dsh-phalanx/releases/download/v0.1.6/acceptance.md) and [formal 0.1.5 → 0.1.6 Web upgrade](https://github.com/dake6767/dsh-phalanx/blob/796f77ade1e41ac53c0a3e5abbc50a791bf90f23/releases/acceptance/0.1.6-web.md). The formal release promotes the original accepted candidate bytes without rebuilding. The Web upgrade retained accounts, spaces, shared models, sessions, files and appearance; a new model turn and repeated-installation checks passed.

## 简体中文

- 修复 HTTP 页面中浏览器未提供 `crypto.randomUUID` 时无法添加共享模型供应商及模型行的问题。草稿行改用本地标识，已保存模型身份不变。
- 在真实非安全浏览器上下文中，针对打包后的平台验证供应商创建、模型独立编辑、删除及保存。

从正式 0.1.5 通过「系统设置 → 检查更新」升级。确认应用后重启服务并中断运行任务。保留账户、稳定空间、共享模型配置及偏好；账户数据版本、DSH 版本、环境代次和升级协议不变。

已完成[候选验收](https://github.com/dake6767/dsh-phalanx/releases/download/v0.1.6/acceptance.md)及[正式 0.1.5 → 0.1.6 Web 升级](https://github.com/dake6767/dsh-phalanx/blob/796f77ade1e41ac53c0a3e5abbc50a791bf90f23/releases/acceptance/0.1.6-web.md)。正式版沿用已验收候选的原始字节，不重新构建。Web 升级保留账户、空间、共享模型、会话、文件和外观；新模型回合及重复安装检查通过。
