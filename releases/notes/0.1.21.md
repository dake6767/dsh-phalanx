# 0.1.21

## English

Administrators can inspect **Usage records** across three tabs: tool calls,
shared-model token totals and self-reported platform skill use. Tool records
cover platform plugin upstreams, remote and shared-runtime MCP services,
platform execution and network tools. Shared-model totals include title
requests and distinguish unknown counters from zero.

Skill reports are supplied by member instances and checked against current
access. They are a reference, not a verified count. Personal skills, local
plugin tools and member-container MCP calls are outside this reporting scope.
See [Usage records](../../docs/install.md#usage-records) for filters, UTC time
boundaries, retention and the complete coverage limits.

### Upgrade from 0.1.20

Use the normal verified update path from formal 0.1.20. Existing execution and
MCP records are imported once into Usage records; the old execution records
page is replaced. Execution limits and member navigation remain unchanged.
The original record files remain available for backup. DSH remains pinned to
`dsh-v0.2.1-rc.2`.

## 简体中文

管理员可在**使用记录**的三个标签中查看工具调用、共享模型 token 汇总和
平台技能自报使用。工具记录覆盖平台插件上游、远程与共享运行 MCP 服务、
平台代执行和网络工具。共享模型汇总包含标题生成请求，并区分未知计数与零。

技能自报由成员实例提交，平台按当前有效持有校验，仅供参考，不代表已核实
的使用次数。个人技能、插件本地工具和成员容器 MCP 调用不在自报范围内。
筛选、UTC 时间边界、保留天数和完整覆盖限制见
[使用记录](../../docs/install.zh-CN.md#使用记录)。

### 从 0.1.20 升级

从正式 0.1.20 按常规校验升级流程更新。已有代执行和 MCP 记录一次性导入
使用记录，原平台代执行记录页由新页取代。执行上限和成员导航保持不变，
原始记录文件保留供备份。DSH 继续固定为 `dsh-v0.2.1-rc.2`。
