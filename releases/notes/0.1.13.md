# 0.1.13

## English

Candidate qualification is in progress. This record does not announce a formal release.

- Recover shared MCP connections after idle reclamation in the same member
  session. Calls whose results are unknown are not automatically replayed.
- Add an administrator MCP market with **Amap and 12306**. Importing a preset
  prepares dependencies and tests the connection; administrators then choose
  grants or publication. Manual MCP configuration remains available.
- Keep preset connection details platform-maintained. Administrators choose when
  to update imported services; a failed candidate leaves the active service in
  place and successful updates retain management settings and member choices.
- Check upgrade storage before large downloads and service interruption. Reclaim
  unused owned images, installation archives and programs, retaining the current
  and most recent successful previous version plus resources still referenced by
  processes, containers or unfinished recovery. Data backups remain protected.
- Show capacity, cleanup results and independent cleanup retries on the system
  update page. Cleanup failure does not roll back a successful upgrade.
- Hide the platform service-preview button in DSH. Authenticated preview routes,
  document previews, downloads, account menus and Platform App Center remain.

### Before upgrading

The upgrade acceptance baseline is formal **0.1.12**. Back up platform and member
data and follow [installation and recovery](../../docs/install.md).
Retaining old artifacts does not enable arbitrary downgrades after new writes.
Only Amap and 12306 presets are included; the other proposed presets are deferred.
See [MCP configuration](../../docs/plugin-access.md#mcp-services) for credentials
and supported manual connections.

## 简体中文

候选验收正在进行，本记录不代表已正式发布。

- 共享 MCP 空闲回收后，可在同一成员会话内恢复连接；结果未知的调用不会自动重放。
- 管理员 MCP 市场首批提供**高德和 12306**。引入后自动准备依赖并测试连接，之后由管理员决定授权或发布；手动 MCP 配置继续保留。
- 市场预设的连接细节由平台维护。管理员主动选择更新，候选失败时旧服务继续可用，更新成功后保留管理设置和成员选择。
- 在大下载和停服之前检查升级空间，回收无引用的受管旧镜像、安装包和程序。默认保留当前与最近一个成功旧版本，并保护进程、容器和未完成恢复所需资源；数据备份保留。
- 系统升级页展示容量与清理结果，支持单独重试清理。清理失败不会回滚已成功的升级。
- 隐藏 DSH 中的平台服务预览按钮，保留认证预览路由、文档预览、下载、账户菜单和平台应用中心。

### 升级前

升级验收基线是正式 **0.1.12**。先备份平台与成员数据，再按[安装与恢复](../../docs/install.zh-CN.md)执行。保留旧制品不代表支持产生新写入后任意降级。本版只包含高德和 12306 预设，其余已提出的预设延后。凭据与手动接入说明见 [MCP 配置](../../docs/plugin-access.zh-CN.md#mcp-服务)。
