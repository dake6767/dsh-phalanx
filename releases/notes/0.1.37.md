# 0.1.37

## English

### Catalogs

Plugin cards and details show the software version available to install. The plugin library shows the installed package version when it can verify it. Update dialogs show the old and new software versions when they change, and describe verified changes to package contents, configuration, or runtime dependencies when the software version stays the same.

Search and category filters can be combined in the plugin, skill, and MCP catalogs. Amap and 12306 are now available from the same signed catalog as plugins and skills. Existing MCP services keep their saved configuration, credentials, and access settings through the upgrade.

Shared MCP subscriptions no longer keep an idle member instance running. In-flight tool calls still keep it active.

### Documentation

[Getting started](https://github.com/dake6767/dsh-phalanx/blob/v0.1.37/docs/install.md) covers installation and the first administrator and member sessions. The [documentation index](https://github.com/dake6767/dsh-phalanx/blob/v0.1.37/README.md#documentation) links to the operations, administrator, and member guides, including system updates, data backup, and key storage.

### Upgrade and recovery

Use **System update** to prepare and apply the upgrade from v0.1.36. Keep a current backup of deployment data, member files, and encryption keys before applying the upgrade. To return to the previous release after a successful upgrade, use its matching installer and your pre-upgrade backup. Restoring backed-up data overwrites later changes to that data.

## 简体中文

### 广场

插件卡片和详情显示可安装的软件版本。插件库显示可核实的已安装软件包版本。软件升级时，更新确认会显示升级前后的软件版本。软件版本相同时，更新确认会说明已核实的软件包内容、配置或运行依赖变化。

插件、技能和 MCP 广场均可同时使用搜索和分类筛选。高德地图与 12306 由统一的签名目录提供。已有 MCP 服务在升级后保留配置、凭据和访问设置。

共享 MCP 的后台订阅不再阻止成员实例空闲回收。工具调用期间实例会保持运行。

### 文档

[快速开始](https://github.com/dake6767/dsh-phalanx/blob/v0.1.37/docs/install.zh-CN.md) 涵盖安装、管理员初始化和成员首次使用。[文档索引](https://github.com/dake6767/dsh-phalanx/blob/v0.1.37/README.zh-CN.md#文档导航) 汇总运维、管理员和成员指南，包括系统升级、数据备份和密钥存储说明。

### 升级与回退

从 v0.1.36 升级时，可在「系统升级」准备并应用升级。升级前请备份部署数据、成员文件及加密密钥。升级成功后如需主动回退，请使用与旧版匹配的安装器和升级前备份。恢复备份会覆盖对应数据在升级后的改动。
