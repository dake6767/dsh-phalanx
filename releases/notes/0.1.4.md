# 0.1.4

- Refreshed administration layout with consistent navigation, account metrics, typography and responsive tables, retaining System/Light/Dark appearance.
- HeroUI account drawers, selection controls, action confirmations and feedback across account, model and system settings pages. Existing permissions, explicit saves and draft protection are preserved.
- Independent themed sign-in presentation and shared platform appearance; platform pages remain in English.
- DSH account entry aligned with the native sidebar. Account menu labels, hints and accessible names now follow the current DSH language, with Chinese and English translations and the upstream fallback mechanism.

The account schema, stable spaces, runtime revision and two-phase CLI/Web upgrade protocol are unchanged. Applying an update still interrupts running tasks after confirmation.

Validated against the original v0.1.4-rc.1 artifacts: Mac/Linux source checks, actual installed DSH/UI regressions, trusted HTTPS/WSS, clean Ubuntu install and reboot, and formal 0.1.3 upgrade with data retention. See [acceptance details](../acceptance/0.1.4.md). Formal promotion uses these same verified artifacts.
