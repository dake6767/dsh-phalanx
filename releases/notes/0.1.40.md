# 0.1.40

## English

### Changes

- Configure each supported catalog plugin feature during installation, or save it later from the catalog or plugin library. The plugin library keeps advanced manual settings and works when the catalog is offline.
- Media Desk can use its own image service settings alongside text and presentation features. The catalog update to Media Desk 2.7.2 carries forward existing image-service settings and the member's selected model.
- Qiaomu Cover Design 0.1.7 supports separate conversation and image-generation settings. Administrators can select an OpenAI-compatible or Seedream image service.
- The catalog and plugin library share the uninstall preview, including dependent entries and unused runtime dependencies. Independent native copies and member works are preserved. App Center clears access notices for the removed service.
- Members can install the compatible Guizang Design catalog package from App Center and retry a failed installation. Members installing a compatible archive through native DSH can open their gallery, works and thumbnails in their own space.
- Members using native billion-context can opt in to the authenticated remote panel for their own space.

## 简体中文

### 更新内容

- 安装广场插件时可以按功能填写接入配置，也可以稍后从广场或插件库维护。插件库提供高级手动设置，广场离线时仍可使用。
- Media Desk 的生图服务可独立配置，同时支持文字和演示文稿功能。广场升级到 Media Desk 2.7.2 时沿用已有生图设置和成员选择的模型。
- 乔木封面设计 0.1.7 的对话与生图可分别配置，生图可选择 OpenAI 兼容或 Seedream 接口。
- 广场和插件库共用卸载预览，显示引用条目及可回收的运行依赖。独立原生副本和成员作品会保留。应用中心会清除已撤销服务的接入提示。
- 成员可在应用中心安装兼容的歸藏设计广场包，并重试失败的安装。通过原生 DSH 安装兼容归档后，成员可在自己的空间打开画廊、作品和缩略图。
- 使用原生 billion-context 的成员可自行启用远程面板，通过本人已认证的空间访问。
