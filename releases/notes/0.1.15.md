# 0.1.15

## English

This release adds administrator-managed runtime dependencies shared by skills,
platform execution and MCP services. It also includes the member contribution
workflow prepared for 0.1.14, which was not released separately.

- Prepare reviewed CLI tools once, inspect preparation logs and checks, then
  reference them from skills, delegated commands or MCP services. Prepared files
  are read-only; replacements switch atomically while active calls retain their
  original version. Failed preparation leaves the usable version available.
- Grant skill dependencies through the existing skill and pack permissions.
  New sessions and calls use current commands without restarting the member
  instance. Revoking the last grant removes access to subsequent calls.
- Migrate 0.1.10 skill preparation and existing MCP preparation automatically into
  runtime dependencies. A failed migration retains the old installation and
  reports the fallback for administrator repair. Preparation receives no platform
  credentials; credential rotation affects subsequent execution without a rebuild.
- Rename the administrator MCP market to **MCP plaza**, retain existing imported
  services and choices, and support non-localhost HTTP deployments alongside HTTPS.
- Let members contribute reviewed skills and plugins from their DSH session.
  Skill contributions declare required command names and installation guidance;
  administrators select or prepare dependencies during adoption. This declaration
  format is incompatible with the unreleased 0.1.14 `execution.prepare` field,
  which is ignored rather than migrated. Existing adopted execution settings are
  migrated separately and retained.
- Provide administrator recipes for OfficeCLI, MiniMax, Feishu bot and WeCom.
  Platform execution works from native agent Bash through the official DSH shell
  environment interface. Member management and plugin management keep their
  existing page structure and HeroUI presentation.

### Before upgrading

Upgrade acceptance covers formal **0.1.13** and the accepted **0.1.14 candidate**.
Back up platform and member data, then follow [installation and recovery](../../docs/install.md).
Review migrated preparation logs and the [CLI configuration examples](../../docs/skill-execution.md#cli-configuration-examples).
The deployer can read the user data root, including personal credentials saved by
members. Shared dependencies contain no platform credentials. Personal login,
such as WeCom QR authorization, remains the member's responsibility.

## 简体中文

本版新增由管理员管理的运行依赖，供技能、平台代执行和 MCP 服务统一引用；同时包含原计划用于 0.1.14 的成员贡献流程，不再单独发布 0.1.14。

- 已审查的 CLI 工具只需准备一次，管理员可查看日志与检查结果，再由技能、代执行命令或 MCP 服务引用。产物只读，替换时原子切换，执行中的调用保留原版本；准备失败时继续使用可用版本。
- 通过既有技能与技能包权限授权依赖。新会话和后续调用无需重启成员实例即可使用当前命令；移除最后一项授权后，后续调用失去权限。
- 自动把 0.1.10 技能准备配置和已有 MCP 准备迁移为运行依赖。迁移准备失败时保留旧产物并提示管理员修复。准备过程不带平台凭据；更换凭据直接影响后续执行，无需重新准备。
- 管理员 MCP 市场更名为 **MCP 广场**，保留已引入服务和成员选择，并支持非 localhost 的 HTTP 部署及 HTTPS 部署。
- 成员可在 DSH 会话中贡献技能和插件。技能声明改为所需命令名称与安装说明，管理员采纳时选择或准备依赖。此格式与未单独发布的 0.1.14 `execution.prepare` 字段不兼容，旧声明字段会被忽略，不迁移；已采纳的代执行配置另行迁移并保留。
- 提供 OfficeCLI、MiniMax、飞书机器人和企业微信的管理员接入步骤。通过 DSH 官方 shell 环境接口支持原生 agent Bash 调用平台代执行。成员管理和插件管理保留既有页面结构与 HeroUI 样式。

### 升级前

升级验收覆盖正式 **0.1.13** 和已验收的 **0.1.14 候选**。先备份平台与成员数据，再按[安装与恢复](../../docs/install.zh-CN.md)操作。检查迁移后的准备日志，并参照 [CLI 配置示例](../../docs/skill-execution.zh-CN.md#cli-配置示例)。部署者可以读取用户数据根，包括成员自行保存的个人凭据。共享依赖不含平台凭据；企业微信扫码等个人登录仍由成员自行完成。
