# 0.1.12 — MCP services and the platform app center

## English

Unreleased draft. Integration and upgrade acceptance are still pending; this is not
an acceptance record or a published release announcement.

- Add an MCP library with group grants, optional member selection, required
  services, connection testing and administrator tool restrictions.
- Support remote Streamable HTTP services, isolated shared command execution and
  member-container commands. Platform credentials remain outside member spaces;
  member-container commands cannot use them. OAuth-only and signature-based
  authentication remain unsupported; use a provider's PAT/API token when available.
- Refresh MCP access and member enable/disable choices without instance restarts.
  Effective platform services take priority over same-name member configuration.
- Complete the DSH platform app center with **Plugins | Skills | Skill packs | MCP
  services**. Skills from grants and packs no longer duplicate individual choices.
- Remove the standalone `/market` page. Open Platform apps from the DSH sidebar,
  account menu or recovery page. Native DSH plugin management remains available.

### Before upgrading

Back up the platform data root and member storage. Replace `/market` bookmarks with
the DSH platform app center entry. Review [installation and recovery](../../docs/install.md)
and [MCP access and trust boundaries](../../docs/plugin-access.md#mcp-services).
The formal 0.1.11 upgrade and the combined real-service acceptance must complete
before this draft can be finalized.

## 简体中文

未发布草稿。组合与升级验收仍待完成；本文不是验收记录或正式发布公告。

- 新增 MCP 库，支持分组授权、成员自选、必选服务、连接测试和管理员停用工具。
- 支持远程 Streamable HTTP 服务、隔离共享命令执行和成员容器命令。平台凭据留在成员空间之外，成员容器命令不能使用平台凭据。暂不支持仅 OAuth 或签名鉴权；提供方支持时可改用 PAT/API Token。
- MCP 授权及成员启停无需重启实例即可生效。生效中的平台服务优先于成员同名配置。
- DSH 平台应用中心补齐「插件 | 技能 | 技能包 | MCP 服务」四个页签，经授权或技能包获得的技能不再重复展示为独立自选。
- 删除独立 `/market` 页面，改从 DSH 侧栏、账户菜单或恢复页进入平台应用；DSH 原生插件管理仍可使用。

### 升级前

备份平台数据根目录和成员存储，将 `/market` 书签改为 DSH 平台应用中心入口。参阅[安装与恢复](../../docs/install.zh-CN.md)及 [MCP 接入与信任边界](../../docs/plugin-access.zh-CN.md#mcp-服务)。正式 0.1.11 升级和真实服务组合验收完成后，才能定稿。
