# 0.1.5

## English

- English and Simplified Chinese across account management, model management, system settings, sign-in, first-administrator initialization and instance recovery. Platform language is a browser-local preference, shared by platform pages and independent of DSH's own language.
- Typed API error codes and parameters alongside the existing English error field. Known errors appear in the selected platform language; unknown codes retain the server's English description.
- Provider and model switch tracks respond to pointer clicks. Add provider focuses the name field, brings it into view on narrow screens and preserves an existing new-provider draft.
- Rewritten English and Chinese READMEs, shared light/dark architecture diagrams, consolidated installation and contribution guides, and CI checks for documentation consistency and links.
- Preinstalled, pinned pnpm for new user spaces, so plugin installation does not first need to download a newer package manager.

Upgrade from formal 0.1.4 through **System settings → Check for updates**. Applying the update restarts services and interrupts running tasks after confirmation. Accounts, stable user spaces, shared model configuration and appearance preferences are retained. Account schema, DSH revision, environment epoch and the two-phase upgrade protocol are unchanged.

Platform language does not translate installer/CLI output, diagnostic logs or DSH's native UI. DSH's account menu continues to follow the language selected within DSH.

Verification completed: [candidate acceptance](https://github.com/dake6767/dsh-phalanx/releases/download/v0.1.5/acceptance.md) and [formal 0.1.4 → 0.1.5 Web upgrade acceptance](https://github.com/dake6767/dsh-phalanx/blob/4ab8a41273e94611c56c15a84f5d7fc80bae0c2d/releases/acceptance/0.1.5-web.md). The formal release uses the original accepted candidate bytes without rebuilding.

## 简体中文

- 账户管理、模型管理、系统设置、登录、首位管理员初始化和实例恢复支持英文及简体中文。平台语言为浏览器本地偏好，平台页面共享，与 DSH 自身语言独立。
- API 在保留既有英文错误字段的同时提供类型化错误码及参数；已知错误按平台语言显示，未知错误保留服务端英文说明。
- 供应商和模型开关轨道可响应点击；添加供应商会聚焦名称输入、在窄屏滚动至可见位置，并保留已有新供应商草稿。
- 重写中英 README，共享明暗主题架构图，整理安装及贡献指南，并在 CI 检查文档一致性和链接。
- 新成员空间预装固定版本的 pnpm，安装插件前无需先下载更高版本的包管理器。

从正式 0.1.4 通过「系统设置 → 检查更新」升级。确认应用后重启服务并中断运行任务。保留账户、稳定空间、共享模型配置及外观偏好；账户数据版本、DSH 版本、环境代次和两阶段升级协议不变。

平台语言不翻译安装器/CLI 输出、诊断日志或 DSH 原生界面；DSH 账户菜单仍跟随 DSH 内选择的语言。

已完成[候选验收](https://github.com/dake6767/dsh-phalanx/releases/download/v0.1.5/acceptance.md)及[正式 0.1.4 → 0.1.5 Web 升级验收](https://github.com/dake6767/dsh-phalanx/blob/4ab8a41273e94611c56c15a84f5d7fc80bae0c2d/releases/acceptance/0.1.5-web.md)。正式版沿用已验收候选的原始字节，不重新构建。
