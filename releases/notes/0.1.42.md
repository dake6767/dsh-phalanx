# 0.1.42

## English

### Changes

- Faster local and hosted validation: automatic two-worker defaults on 16 GiB or smaller hosts, controlled parallel browser checks with completeness-checked caching, faster test database and fixture setup, and 8-shard duration-balanced dual-architecture Linux acceptance.
- Release notes and acceptance records no longer invalidate cached local product validation results.
- Split architecture documentation into a concise core blueprint plus subsystem documents under `docs/architecture/`, and expanded `docs:check` to enforce heading symmetry across all seven bilingual guide pairs.
- No runtime product behavior or pinned upstream DSH version changes; existing deployments upgrade directly from supported prior releases.

## 简体中文

### 更新内容

- 提速本地与托管验收：16 GiB 及以下宿主机自动默认双 worker、受控并行浏览器检查与完整性校验缓存、测试数据库与夹具提速，以及按实测耗时均衡的双架构 8 分片 Linux 验收。
- 发布说明与验收回执改动不再使已通过的本地产品验收缓存失效。
- 将架构文档拆分为精简核心蓝图与 `docs/architecture/` 子系统专题文档，并将 `docs:check` 双语标题结构对称校验扩展至全部七对指南文档。
- 本版不改动运行时产品行为与上游 DSH 固定版本，既有部署可从受支持的先前版本直接升级。
