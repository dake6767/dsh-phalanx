# 0.1.30

## English

### Debian-family installation

The installer accepts Ubuntu, Debian and their derivatives by distribution family
and host capabilities. Ubuntu 24.04 and 26.04 are on the verified list; other
Debian-family distributions receive an unverified warning without an additional
confirmation. Non-Debian hosts are refused before host changes.

Host requirements are Podman 4.9.3 or newer, passt 0.0~git20240220 or newer,
systemd with a working user manager, cgroup v2 and rootless Podman. Failure
diagnostics identify the missing capability and report actual and minimum package
versions. Human and JSON output include host verification status. Installation and
upgrade preparation share these checks.

For newer pasta helpers, the runtime explicitly restores host-loopback to
container-loopback forwarding with `--host-lo-to-ns-lo` when the selected helper
supports it. Older helpers retain their original arguments. DSH and published
host ports remain bound to `127.0.0.1`; the private gateway return path,
UDP/ICMP restrictions and rootless isolation are preserved.

## 简体中文

### Debian 系安装

安装器按发行版系列和主机能力接受 Ubuntu、Debian 及其衍生版。已验证名单包含
Ubuntu 24.04 与 26.04；其他 Debian 系发行版会收到「未验证」警告，无需额外
确认。非 Debian 系主机在修改主机前被拒绝。

主机需要 Podman 4.9.3 或更新版本、passt 0.0~git20240220 或更新版本，以及
systemd、可用的 user manager、cgroup v2 和 rootless Podman。失败提示指出缺少的
能力，并给出软件包实际版本和下限。人类输出和 JSON 输出均带有主机验证状态。
安装与升级准备共用这些检查。

对于新版 pasta，运行时在实际选用的 helper 支持时显式增加 `--host-lo-to-ns-lo`，
恢复宿主 loopback 到容器 loopback 的转发；旧版 helper 保留原参数。DSH 与宿主
发布端口仍监听 `127.0.0.1`，私有网关返回路径、UDP/ICMP 限制和 rootless 隔离
保持不变。
