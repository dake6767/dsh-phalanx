# 0.1.16

## English

This release adds configurable download sources and a complete local Linux
development environment for Apple Silicon Macs.

- Administrators can choose official or mainland China download defaults in
  System settings and customize individual sources for npm, Python packages,
  container images, GHCR, GitHub assets and API requests, and browsers. Saved
  choices apply to subsequent preparation and update operations. Explicit
  preparation settings retain precedence over defaults.
- The installer accepts the same presets and GitHub proxy prefixes. Downloads
  retain their original checksum and image-digest verification. Source changes
  do not rebuild or replace already prepared dependencies automatically.
- Contributors can build, install, upgrade and exercise the complete product in
  an owned Lima VM with one command. The development environment includes a
  local model fixture; real providers can be configured through Administration.
  Native Linux CI and the VM share the same explicit container-test inventory.
- Internal candidates use workflow-run identities in a separate unsupported
  candidate repository. Formal promotion reuses accepted package bytes and
  image digests without rebuilding.

### Before upgrading

Back up platform and member data, then follow
[installation and recovery](../../docs/install.md). Existing installations keep
their saved download choices. Review System settings before selecting a new
preset; changing a source does not change the identity of a published release.
See [Contributing](../../CONTRIBUTING.md) for the Mac development workflow.


Existing 0.1.15 web updaters do not recognize the new run-ID manifest identity
and report `Update availability unknown: Invalid release manifest` when checking
for this release. Before using the web update flow, download the current
installer as described in the installation guide and run it once:

```sh
sudo bash install.sh --upgrade bootstrap --version v0.1.16 --output json
```

This verifies and updates only the small updater from this release. The platform
keeps running its installed version; platform data and member workspaces stay in
place. Return to System settings, check again, then download and apply the update
when ready. Finish or recover any prepared or interrupted update before this step.

## 简体中文

本版新增可配置的下载源，以及面向 Apple Silicon Mac 的完整本地 Linux 开发环境。

- 管理员可在系统设置中选择官方或中国大陆下载预设，并分别调整 npm、Python 包、容器镜像、GHCR、GitHub 资产与 API、浏览器的下载源。保存后用于后续准备和更新操作；准备配置中显式指定的来源优先于默认值。
- 安装器支持相同预设和 GitHub 代理前缀。下载仍按原始校验和与镜像 digest 核验；切换来源不会自动重建或替换已经准备好的依赖。
- 贡献者可用一条命令在独立 Lima VM 中构建、安装、升级并运行完整产品。开发环境包含本地模型夹具，也可通过管理界面配置真实提供方。原生 Linux CI 与 VM 使用同一份明确的容器测试清单。
- 内部候选以工作流运行编号标识，发布到独立且不提供支持的候选仓库。正式晋级复用已验收的包字节与镜像 digest，不重新构建。

### 升级前

先备份平台与成员数据，再按[安装与恢复](../../docs/install.zh-CN.md)操作。已有安装保留已保存的下载配置；选择新预设前请检查系统设置。切换下载源不会改变已发布版本的身份。Mac 开发流程见[贡献指南](../../CONTRIBUTING.md)。


0.1.15 的网页升级执行器不认识新的 run-ID 清单身份，检查本版时会显示
`Update availability unknown: Invalid release manifest`。使用网页升级前，
先按安装指南下载当前安装器，再执行一次：

```sh
sudo bash install.sh --upgrade bootstrap --version v0.1.16 --output json
```

这一步只校验并更新本版的小型升级执行器，平台继续运行已安装版本，平台数据和
成员工作区保留。完成后回到系统设置重新检查更新，再按需下载和应用升级。
如已有准备完成或中断的升级操作，须先完成或恢复。
