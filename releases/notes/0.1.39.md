# 0.1.39

## English

### Changes

- DSH is pinned to `dsh-v0.2.2-rc.5`. Web search uses DeepSeek Search API through the platform's existing search settings.
- Catalog plugins can share a prepared Playwright browser build. Plugins that require different Chromium builds can run in the same member instance.
- Members can open Guizang Design from the DSH sidebar to browse their own work, render cards, and export web pages to PDF or a long image. Existing Huashu Design installations can continue to export PDFs.
- Administrators can see disk usage and plugin references for each Chromium build. Uninstall offers to reclaim unused builds and keeps the ones other plugins or member copies still use.
- Administrators can import dsh-image-gen before entering its upstream settings. Members can generate and edit images once the service is configured.
- Catalog installations of Mnemon enable web memory management by default. Members who explicitly selected read-only access keep that setting.

## 简体中文

### 更新内容

- DSH 固定为 `dsh-v0.2.2-rc.5`。联网搜索通过平台现有搜索设置使用 DeepSeek Search API。
- 广场插件可以共用已准备的 Playwright 浏览器。需要不同 Chromium 构建的插件可以在同一成员实例使用。
- 成员可以从 DSH 侧栏打开歸藏设计，浏览自己的作品、渲染卡片，并将网页导出为 PDF 或长图。已有花叔设计安装可以继续导出 PDF。
- 管理员可查看每个 Chromium 构建的磁盘占用和引用插件。卸载时可回收闲置构建，其他插件或成员副本仍在使用的构建会保留。
- 管理员可先从广场引入 dsh-image-gen，再配置上游服务。配置完成后，成员可生成和编辑图片。
- 从广场安装 Mnemon 时默认启用网页记忆管理。成员显式设置的只读访问会保留。
