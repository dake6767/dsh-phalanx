# 0.1.23

## English

Ordinary plugins installed from Platform apps are now native DSH installations.
Members can save settings, disable, upgrade and uninstall their copies. Unpublishing
or removing a library entry keeps existing native copies and settings. Group details
separate **Platform controlled** read-only grants from one-time **Preinstalled plugins** delivery.
Shared-credential selections remain read-only. Existing selected or expert read-only
access takes priority over a coexisting preinstalled copy.

Preinstalls run in the background after the instance is ready. Uninstalling, moving a
member or removing and re-adding a list entry does not reinstall a delivered package.
Resetting the DSH environment installs once from the current preinstall list; native
self-selections must be installed again by the member. See
[Groups and plugins](../../docs/install.md#groups-and-plugins).

### Upgrade from 0.1.22

Old plugin selections are cleared once; members must select or install their plugins
again. Existing native files remain. Administrator groups no longer automatically
receive library plugins, skills, MCP services or experts: configure each explicitly
before using it in the administrator's DSH. Library management privileges still come
from the account's administrator role. DSH remains pinned to `dsh-v0.2.1-rc.2`.

## 简体中文

从「平台应用」安装的普通插件现在是原生 DSH 安装，成员可保存设置、停用、
自行升级及卸载。下架或移除库条目保留已有原生副本与设置。分组详情把只读
的「平台管控」与一次性的「预装插件」分开；共享凭据自选仍只读加载。已有自选
或专家只读资格优先于同名预装副本。

预装在实例就绪后后台执行。成员卸载、换组、移出再加入清单都不重复安装已
交付包；重置 DSH 环境后按当前清单重新预装，自选原生插件由成员重新安装。
详见[分组与插件](../../docs/install.zh-CN.md#分组与插件)。

### 从 0.1.22 升级

旧插件自选记录一次性清空，成员需要重新选择或安装；已有原生文件保留。
管理员分组不再自动获得库中插件、技能、MCP 服务及专家，使用前须逐项显式
配置到管理员分组。库的管理权限仍来自账户管理员身份。DSH 继续固定为
`dsh-v0.2.1-rc.2`。
