# 0.1.3

## English

Candidate `v0.1.3-rc.1` passed the [complete acceptance](https://github.com/dake6767/dsh-phalanx/releases/download/v0.1.3/acceptance.md).
The formal release promotes these accepted candidate artifacts without rebuilding.

- HeroUI management shell with stable Account management, Model management and System settings routes, responsive navigation and shared System/Light/Dark appearance.
- Account creation/editing drawers, independent contact-email updates and explicit account actions. Usernames, sessions and spaces are preserved by email updates.
- Provider selection beside an inline editor, stable model rows, explicit saves, draft protection and retained drafts on revision conflicts.
- System update phase/action, real download progress and elapsed times, folded diagnostics, explicit errors and original-operation reconnect behavior.
- Independent themed login, initialization and recovery pages with complete error feedback.
- Native DSH sidebar account avatar/menu through the official footer slot; Restart instance and Log out, protected plugin files and retained native Settings.
- Bounded interactive and redirected installer progress, known-total percentages, separate phase/total clocks and complete restricted diagnostics. JSON stdout remains unchanged.

Managed 0.1.2 keeps the same two-phase CLI/Web upgrade protocol, account schema,
stable spaces and storage identity. Applying an update still interrupts running
tasks immediately after confirmation. Both formal 0.1.2 upgrade paths and pristine Ubuntu installation passed against
the same original CI candidate assets. The formal release preserves those exact bytes.

## 简体中文

- 新增 HeroUI 管理界面，保留账户管理、模型管理和系统设置路由，支持响应式导航及系统/浅色/深色外观。
- 账户创建与编辑使用抽屉，联系邮箱可独立更新，账户操作有明确入口；修改邮箱保留用户名、会话和空间。
- 供应商选择旁提供内联编辑，模型行保持稳定；明确保存，保护草稿，版本冲突时保留输入。
- 系统更新展示阶段、操作、真实下载进度及耗时；诊断信息可折叠，错误明确，重新连接后继续显示原操作。
- 登录、初始化和恢复页独立呈现，统一主题并完整反馈错误。
- 通过 DSH 官方侧边栏底部扩展位提供账户头像与菜单，支持重启实例和退出登录；保护插件文件并保留原生设置。
- 安装器在交互及重定向场景下提供有界进度输出、已知总量百分比、阶段和总耗时及受限诊断；JSON 标准输出不变。

从受管理的 0.1.2 升级时，两阶段 CLI/Web 协议、账户数据版本、稳定空间和存储身份不变。确认应用更新后仍会立即中断运行任务。正式 0.1.2 的两种升级入口及干净 Ubuntu 安装已使用同一份 CI 候选产物通过验收；正式版沿用这些原始产物。详见[完整验收](https://github.com/dake6767/dsh-phalanx/releases/download/v0.1.3/acceptance.md)。
