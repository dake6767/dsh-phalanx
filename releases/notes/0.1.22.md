# 0.1.22

## English

Member entry now shows startup progress while an instance is starting or recovering. Request handling and shared MCP connections have fewer repeated steps; shared MCP runtimes stay available for 300 seconds of inactivity.

Administrators can set default and per-member CPU, memory and process limits, apply them to running instances, and review capacity guidance. Idle reclamation is configurable in System settings. Resident instances start after platform startup and recover from confirmed unexpected exits.

Members can reset their own DSH environment with confirmation. The platform keeps the latest three environment backups and preserves projects, personal files and chat. See [Member instances](../../docs/install.md#member-instances) and the reset instructions in the installation guide.

### Upgrade from 0.1.21

This release carries explicit maintainer waivers for remaining offline upgrade acceptance and pristine installation. Offline resident recovery failed after a 300-second wait; pristine installation was not run. The existing 0.1.21 management UI and current formal CLI installer reject waiver-bearing acceptance receipts, so installation/upgrade through those validators is unavailable for this release. No bypass is provided. Mainland online upgrade and smoke passed in acceptance. Existing deployment resource and idle parameters are imported once into saved settings; later changes belong in administration. Deployments without earlier resource limits remain unlimited. Applying limits or restarting resident instances can interrupt tasks. DSH remains pinned to `dsh-v0.2.1-rc.2`.

## 简体中文

成员进入工作区时，可查看实例启动或回收后恢复的进度。请求链路和共享 MCP 连接减少重复处理；共享 MCP 运行时在空闲 300 秒后回收。

管理员可设置默认及成员独立的 CPU、内存和进程额度，应用到运行实例，并查看容量提示。系统设置可修改空闲回收时长。常驻实例会在平台启动后自动启动，并在确认意外退出后恢复。

成员可确认后重置自己的 DSH 环境；平台保留最近三份环境备份，项目、个人文件和聊天保持。用法见[成员实例](../../docs/install.zh-CN.md#成员实例)及安装指南中的重置说明。

### 从 0.1.21 升级

本版由维护者明确豁免剩余离线升级验收与全新安装验收：离线常驻恢复等待300秒失败，全新安装未运行。现有0.1.21管理界面与当前正式CLI安装器会拒绝带豁免的验收回执，因此本版无法通过这些校验入口安装或升级；不提供绕过方法。验收中的大陆在线升级与smoke已通过。已有部署资源额度和空闲参数只导入一次，后续通过管理页面修改；此前未设置资源额度的部署保持不限。应用额度或重启常驻实例可能中断任务。DSH 继续固定为 `dsh-v0.2.1-rc.2`。
