# 0.1.35

## English

### Install and configure Catalog items

Open a plugin or skill card in the administrator Catalog to review its contents, shared dependencies, service settings, and distribution options. Use the install button at the bottom of the drawer. For supported plugins, choose group preinstallation or let eligible members install the plugin from the Platform App Center. You can also install a Catalog item without distributing it.

For supported plugins such as Qiaomu Cover, administrators can configure chat and image generation independently. OpenAI-compatible chat and image generation are supported, along with Seedream text-to-image and reference-image generation. Use the installed item’s settings to finish a configuration you skipped at install time. Installed settings remain editable when the Catalog is offline. Saving settings does not test the backend or restart member instances.

If platform setup fails after installation, the item stays installed. Administrators can retry from the Catalog drawer. Members can retry service setup from the Platform App Center. Members can choose platform or personal settings for each supported service in DSH. If a platform service fails or access is withdrawn, members can explicitly switch to personal settings. A member who loses access keeps the installed copy and personal settings. A failed request does not automatically use a personal key.

### Skills and design plugins

Administrators can edit a Catalog skill pack’s display name and description. Updates preserve each edited field and refresh the other fields from the Catalog. The pack’s skills and workflow remain managed by the Catalog. Search within a pack from its details, or use **Add skills** to select members of a manually managed pack.

DrawAI and Huashu Design are available for compatible deployments through the Catalog. Their declared shared dependencies are prepared during installation so newly preinstalled members can open the plugins on their first visit to DSH.

### Upgrade

From v0.1.34, update the upgrade executor before preparing the upgrade. The new executor can read backup inventories from larger deployments.

```sh
curl -fsSLo install.sh https://raw.githubusercontent.com/dake6767/dsh-phalanx/v0.1.35/install.sh &&
  sudo bash install.sh --upgrade bootstrap --version v0.1.35 --output json
```

The platform keeps running during this step. When the command reports `updater-ready`, open **System update**, check again, then prepare and apply the upgrade. The upgrade retains deployment data, settings, and member files. Existing member plugin copies keep their current settings. Platform services require a supported platform-delivered copy. The bundled DSH revision is `dsh-v0.2.2-rc.1`.

### Known issue

Occasionally, sending a message in DSH fails with a temporary gateway error (HTTP 502). It has been observed on the first message in a newly created session. If this happens, send the message again. A fix is planned for the next release.

## 简体中文

### 从广场安装和配置

在管理后台的插件广场或技能广场打开条目卡片，在详情抽屉内查看安装内容、共享依赖、服务配置和分发选项，确认后点击底部的安装按钮。支持的平台插件可按分组预装，也可开放给有资格的成员在平台应用中心自选安装。管理员也可以只安装，稍后再分发。

乔木封面等已适配插件的对话和生图可以分别配置。平台支持 OpenAI 兼容对话和生图，也支持 Seedream 文字及参考图生图。安装时跳过的配置可到已安装条目的设置中补填。广场离线时仍可维护已安装设置。保存时不会请求后端测试连通性，也不会自动重启成员实例。

插件安装后若平台接入失败，安装结果会保留。管理员可在广场抽屉重试配置，成员可在平台应用中心重试服务接入。成员可以在 DSH 中按服务选择平台或个人配置。平台服务出错或资格被撤销时，成员可主动切换到个人配置。失去资格的成员仍保留已安装副本和个人配置。失败的请求不会自动使用个人 Key。

### 技能包与设计插件

管理员可修改广场技能包的展示名称和描述。广场更新会保留各个已编辑的字段，未编辑字段随广场刷新。包内技能与编排由广场维护。详情支持搜索包内技能，手动管理的技能包可通过「添加技能」选入技能。

兼容版本可通过插件广场安装 DrawAI 和 Huashu Design。安装时会准备条目声明的共享依赖，分组预装成员首次进入 DSH 即可打开插件。

### 升级

从 v0.1.34 升级时，先更新一次升级执行器。新版执行器可以读取较大部署生成的备份清单。

```sh
curl -fsSLo install.sh https://raw.githubusercontent.com/dake6767/dsh-phalanx/v0.1.35/install.sh &&
  sudo bash install.sh --upgrade bootstrap --version v0.1.35 --output json
```

更新执行器期间平台持续运行。命令返回 `updater-ready` 后，回到「系统升级」重新检查，再准备并应用升级。升级保留部署数据、配置和成员文件。升级前的成员插件副本保留原有设置。使用平台服务需要由平台交付的适配副本。随平台提供的 DSH 版本为 `dsh-v0.2.2-rc.1`。

### 已知问题

在 DSH 中发送消息时，偶尔会返回临时网关错误（HTTP 502），目前见于新建会话后的第一条消息。遇到时请重新发送。下一版将修复。
