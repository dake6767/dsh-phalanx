# 0.1.14

## English

Members can contribute plugins and skills through an agent, with file checks, value-free declarations and a foreground confirmation card. Administrators review, configure platform credentials and choose grants or publication in the Member contributions tab. Skill dependency preparation still requires an explicit administrator action.

New contributed entries have a maintainer and version history. Existing and administrator-created entries remain unowned; administrators can transfer or clear maintainership. Only the maintainer can contribute same-name updates. Plugin versions must increase; skill reviews show file differences. Updates retain current settings and write-only credentials and mark changed declarations. Contribution credit can be anonymous.

Authorized plugin maintainers can switch to their own local copy in native plugin details and restart their instance. Other members keep the platform version. Local copies receive no platform access settings or upstream credentials; switch off and restart to return to the platform copy.

The management UI retains the member and plugin management layouts and uses HeroUI components. DSH remains pinned to `d743267388641bc76f17c45ce8b4c231aed1d32c`.

## 简体中文

成员可以通过 agent 把插件或技能贡献给平台，先检查文件和不含凭据的声明，再由本人在确认卡片中提交。管理员在「成员贡献」页签审阅、填写平台凭据并选择授权或发布；技能依赖仍需管理员明确点击准备。

插件与技能新增维护人和版本记录。新贡献条目由贡献者维护；已有条目和管理员添加的条目保持无维护人，管理员可以转交或清空。只有维护人可提交同名更新，插件版本必须升高，技能更新显示文件差异。更新保留已有配置和只写凭据，并标出新增与删除的声明项。贡献署名可匿名。

插件维护人可在原生插件详情启用自己的本地副本，重启后平台副本为其让位。其他成员继续使用平台版本；本地副本没有平台接入配置，也不能使用平台上游凭据。关闭后再次重启恢复平台副本。

管理界面沿用成员与插件管理的页面框架、样式和信息组织方式，优先使用 HeroUI 组件。DSH 固定修订仍为 `d743267388641bc76f17c45ce8b4c231aed1d32c`。
