# 0.1.32

## English

### A consistent management and member interface

The management interface now uses consistent cards, drawers, spacing and light
and dark themes. The DSH sidebar groups the platform account and settings gear
on one row. Recovery separates instance restart from resetting the DSH
environment, and the restart entry opens its corresponding tab.

### Updated DSH and per-conversation reasoning

The bundled runtime is now `dsh-v0.2.2-rc.1`. Shared models, skills, plugins,
MCP and platform account controls continue to use the platform integration.

Administrators can enable **Supports reasoning** for each shared model.
Members can then choose a reasoning effort in the DSH conversation input;
the model's protocol determines how that choice reaches the supplier.
The platform does not select a default effort or rewrite the member's choice.
Turning off reasoning support removes the selector. Existing models have
reasoning support turned off until an administrator enables it.

Gateway usage observations also retain reasoning token counts where the
supplier reports them. Missing counters stay unknown.

### Temporarily paused entry points

Expert, usage record and member contribution entry points are temporarily
unavailable. Their existing data is retained, usage collection continues, and
already summoned experts remain usable. This pause does not delete those
features' stored configuration or history.

### Upgrade notes

Upgrading from 0.1.31 preserves accounts, member files, skills and skill packs,
plugin libraries and settings, grants and member selections, and existing
expert, contribution and usage data. The plugin source cleanup introduced in
0.1.31 does not repeat for plugins already recorded by that release.

## 简体中文

### 管理端与成员端界面统一

管理后台统一了卡片、抽屉、间距及日夜主题。DSH 侧栏将平台账户和设置齿轮放在
同一行。恢复页分为重启实例与重置 DSH 环境两个页签，从重启入口进入时直接打开
对应页签。

### DSH 更新与会话推理等级

内置运行时升级为 `dsh-v0.2.2-rc.1`。共享模型、技能、插件、MCP 与平台账户
控制继续通过平台接缝提供。

管理员可以为每个共享模型打开「支持推理」，成员随后可在 DSH 对话输入框中选择
推理等级，由模型协议决定如何传给供应商。平台不设置默认等级，也不改写成员的
选择。关闭支持推理后，选择控件消失；已有模型默认关闭，需管理员主动开启。

网关用量采集同时保留供应商实际报告的思考 token；缺失的计数保持未知。

### 暂时下线部分入口

专家、使用记录和成员贡献入口暂时下线。已有数据保留，使用记录继续采集，已召唤
的专家仍可使用。本次暂停不会删除这些功能的配置或历史。

### 升级说明

从 0.1.31 升级会保留账户、成员文件、技能与技能包、插件库及配置、分组授权、
成员选择，以及已有专家、贡献和使用记录数据。0.1.31 已记录来源的插件不会再次
经历该版引入的旧插件来源清理。
