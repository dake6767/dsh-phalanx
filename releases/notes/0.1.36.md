# 0.1.36

## English

### DSH runtime and platform settings

This release includes `dsh-v0.2.2-rc.3`. It fixes a connection reuse issue that could return HTTP 502 on the first message in a new DSH session. Linux member containers default to Bash for interactive terminals to avoid a timeout while opening an Agent terminal.

In **System settings → DSH features**, administrators can enable web search and voice input. Set the DeepSeek Search API key again in the new settings. Remote microphone access requires HTTPS. Microphone access also works on localhost. The standard INT8 model uses less memory, and the FP32 model is available when higher precision is needed.

### Catalog and administration

The Catalog supports plugins that read service settings from JSON. Media Desk uses these bindings for platform-managed settings. A member who changes a managed field keeps their own value.

Installation drawers show the source, install plan, service backends, and distribution settings. To finish service setup after installation, open **Access settings** in the installed plugin or **Platform execution** in the installed skill. Skill packs list their skills by name.

### Upgrade and recovery

Use **System update** to prepare and apply the upgrade from v0.1.35. The upgrade retains deployment data and member files. Rolling back restores the pre-upgrade backup. It discards conversations created after the upgrade and post-upgrade changes to existing conversations.

## 简体中文

### DSH 运行时与平台设置

本版随平台提供 `dsh-v0.2.2-rc.3`，修复了新建 DSH 会话发送首条消息时可能因连接复用出现的 HTTP 502。Linux 成员容器的交互终端默认使用 Bash，避免 Agent 终端打开时超时。

管理员可在「系统设置 → DSH 功能」启用联网搜索和语音输入。联网搜索需在此重新配置 DeepSeek Search API Key。远程访问需使用 HTTPS 才能开启麦克风，本机通过 localhost 访问时也可使用麦克风。标准 INT8 模型占用较少内存，也可选用高精度 FP32 模型。

### 广场与管理界面

广场支持从 JSON 读取服务设置的插件，自媒体工作台可通过此方式使用平台配置。成员自行修改过的字段保留个人值。

安装抽屉集中显示来源、将安装的内容、服务后端和分发选项。安装时跳过的服务配置可在已安装插件的「接入配置」或已安装技能的「平台代执行」补填。技能包按名称显示包内技能。

### 升级与回退

从 v0.1.35 升级时，可在「系统升级」准备并应用升级。升级保留部署数据及成员文件。回退会恢复升级前备份，升级后新增或改动的会话数据会丢失。
