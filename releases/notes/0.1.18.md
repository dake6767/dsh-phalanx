# 0.1.18

## English

Administrators can install OfficeCLI, MiniMax, Feishu, WeCom and HyperFrames from
the new **Suite catalog** navigation entry. Each suite prepares its pinned CLI,
imports skills and a skill pack, and configures delegated execution where needed.
FFmpeg, Chromium and pandoc are also available as catalog runtime dependencies.
Installation does not grant or publish entries unless the administrator selects
those choices. See [skill execution](../../docs/skill-execution.md#suite-catalog)
for installation, identity, credentials and lifecycle instructions.

Suite entries are read-only until detached. Administrators preview updates and
manual replacements before confirming; shared dependencies are reused, and
failed updates retain recoverable state. Platform upgrades leave installed suites
unchanged. Feishu uses the team app bot only; WeCom requires each member's own
login. HyperFrames supplies local rendering without offline ML engines or a
platform HeyGen account.

### Upgrade from 0.1.17

The supported upgrade source is formal 0.1.17. Upgrade older deployments to
0.1.17 first, following its release notes. Existing skills, dependencies, grants
and member choices remain in place; adopting catalog versions is a separate
administrator action. DSH remains pinned to `dsh-v0.2.1-alpha.5`. With unchanged
image inputs, the release can reuse the verified DSH image digest, avoiding
another image transfer when it is already installed.

## 简体中文

管理员可从新增的一级导航**套件广场**安装 OfficeCLI、MiniMax、飞书、企业微信与
HyperFrames。每个套件准备锁定版本的 CLI，导入技能和技能包，并按需配置代执行。
FFmpeg、Chromium 和 pandoc 也可作为广场运行依赖单独安装。安装本身不授权或
发布，只有管理员主动勾选才执行。安装、身份、凭据及生命周期说明见
[技能代执行文档](../../docs/skill-execution.zh-CN.md#套件广场)。

套件条目脱离之前保持只读。更新和手动替换先预览、再确认；共用依赖复用，更新
失败保留可恢复状态。平台升级不改已安装的套件。飞书只使用团队应用机器人；
企业微信由成员本人登录。HyperFrames 提供本地渲染，不附带离线 ML 引擎或平台
HeyGen 账户。

### 从 0.1.17 升级

受支持的升级来源是正式 0.1.17。更早部署先按对应发布说明升级到 0.1.17。
已有技能、运行依赖、授权和成员自选保持不变；改用广场版本由管理员另行确认。
DSH 继续固定为 `dsh-v0.2.1-alpha.5`。镜像输入不变时，可复用已验证的 DSH 镜像
摘要；已经安装该镜像的部署无需再次传输镜像。
