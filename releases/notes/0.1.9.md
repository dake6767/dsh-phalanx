# 0.1.9

## English

- Add a skill library with ZIP import, file-tree and rendered `SKILL.md` review, same-name replacement and removal. The administrator interface follows the existing plugin and account management layout.
- Add group skill grants and a Skills tab in Platform apps. Administrators receive all available skills; ordinary groups start empty. Members can select published skills, while managed grants remain administrator-controlled.
- Distribute read-only skill files through the official DSH skill provider. Changes apply to new sessions without restarting instances. Members' same-name skills take precedence, with an override notice in Platform apps.
- Preserve skills through environment resets and platform upgrades. Disabled accounts receive no skill projection; account deletion clears its projection and selections. Runtime bundled-name conflicts pause distribution and remain visible in the library.
- Document personal skill key setup. Skills run with member permissions; the platform neither scans their code nor prepares dependencies. Platform credentials continue to apply only to plugins. Platform execution for skills is planned for a later release.

### Upgrade from 0.1.8

Use **System settings → Check for updates**. Preparation keeps the current service running; applying the update restarts services and interrupts running tasks after confirmation.

The skill library starts empty, with no skill grants. Existing plugin libraries, grants, upstreams, access settings, accounts, model configuration, conversations and member files are retained. Account schema, pinned DSH revision and environment epoch are unchanged. See [Skills](../../docs/install.md#skills) for import and member setup.

## 简体中文

- 新增技能库：上传 ZIP 后审阅文件树和渲染后的 `SKILL.md`，支持同名替换与移除。管理页面沿用插件和账户管理的布局。
- 新增分组技能授权，以及「平台应用」中的技能 Tab。管理员自动获得全部可用技能，普通分组初始无技能；成员可自选已发布技能，分组托管授权仍由管理员管理。
- 通过 DSH 官方技能接口分发只读文件。技能变更在新会话生效，无需重启实例；成员同名技能优先，平台应用显示覆盖提示。
- 环境重置和系统升级保留技能。停用账户期间不提供技能目录，删除账户时清理平台技能目录和自选记录；与运行时内置技能同名时暂停分发，技能库保留冲突提示。
- 补充成员自配技能 Key 的方法。技能以成员权限运行，平台不扫描代码、不准备依赖。平台凭据仍仅适用于插件，技能的平台代执行计划在后续版本提供。

### 从 0.1.8 升级

通过「系统设置 → 检查更新」升级。准备期间现有服务继续运行；确认应用更新后会重启服务，并中断正在运行的任务。

技能库初始为空，没有技能授权。已有插件库、授权、上游、接入配置、账户、模型配置、会话和成员文件均保留。账户数据版本、固定的 DSH 版本和环境代次保持不变。导入及成员配置方法见[技能](../../docs/install.zh-CN.md#技能)。
