# 0.1.29

## English

### Native features per group

The **DSH native features** group tab controls native plugin installation, manual
terminal access, and the Standard, PTC, Minimal and Creator Agent presets. All
features remain enabled for existing and new groups by default. Keep at least one
built-in preset enabled. Changes take effect on the next instance start; saving
does not restart running instances.

If a member's default preset is disabled, the default falls back in the order
Standard, PTC, Minimal, Creator. Re-enable a disabled preset to resume sessions
bound to it. Available expert and member-defined defaults remain intact.
Disabling Creator also removes its derived creation entries.
These controls shape the member interface and are not a security isolation
boundary: members retain Agent command execution and writable native profiles.

### Plugin installation and existing copies

Disabling **Add plugins** refuses native npm, git and local-package installation
with a localized message, blocks first-time optional bundle enablement, and
disables Creator's plugin management and market tools. Platform App Center
selections, preinstalls and controlled plugins remain available. Existing native
copies can still be configured, disabled, re-enabled and removed.

Earlier optional-bundle history cannot be recovered. On upgrade, currently
enabled or installed official optional bundles establish re-enablement
eligibility; other bundles are treated as never enabled. Subsequent successful
enablement is recorded for future re-enablement.

### DSH runtime

Updates the supported runtime to `dsh-v0.2.1-rc.5` through official integration
seams. Shared model credentials remain in the platform.

## 简体中文

### 按分组配置原生功能

分组的 **DSH 原生功能**页签可以配置自行添加插件、手动打开终端，以及标准、
PTC、极简、创造四个 Agent 预设。已有和新建分组默认全部开启，至少保留一个
内置预设。改动在成员下次启动实例时生效；保存不会重启正在运行的实例。

成员的默认预设被关闭时，按标准、PTC、极简、创造的顺序回退。重新开启被关闭
的预设后，才能恢复绑定于它的会话。仍可用的专家和成员自建默认预设保持不变。
关闭创造模式也会移除其派生的创建入口。
这些控制用于调整成员界面，不是安全隔离边界：成员仍可让 Agent 执行命令，
也仍有原生配置的写权限。

### 插件安装与已有副本

关闭**自行添加插件**后，原生 npm、git、本地包安装会收到本地化拒绝提示，
首次启用官方可选包也会被拒绝，创造模式的插件管理和插件市场工具同时禁用。
平台应用中心的自选、预装和平台管控仍可使用；已有原生副本仍可设置、停用、
再启用和卸载。

旧版的可选包启用历史无法恢复。升级时，当前已启用或已安装的官方可选包建立
再启用资格，其余视为从未启用；之后成功启用的记录会保留，供以后再启用。

### DSH 运行时

通过官方集成接缝跟进 `dsh-v0.2.1-rc.5`。共享模型凭据继续留在平台内。
