# 0.1.41

## English

### Changes

- A signed catalog can specify a replacement for a plugin's exact previous version and checksum.
- During the transition, the previous member copy retains the matching catalog-pinned shared resources. Members can apply the replacement in App Center.

## 简体中文

### 更新内容

- 签名目录可为同一插件指定替换包，并锁定旧包的确切版本和摘要。
- 迁移期间，旧成员副本继续使用同一份锁定的共享资源。成员可在应用中心确认替换。
