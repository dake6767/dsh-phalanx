# 0.1.44

## English

### Plugin display

- The plugin library and the Platform App Center show plugin artwork and localized names and descriptions. Existing plugins can pick up display information from their saved packages without reinstalling.
- Administrators can edit display names and descriptions, including for plugins imported from the catalog, or restore the defaults. Version and catalog updates keep saved overrides. Group plugin settings display the same names alongside their npm package identifiers.
- Members see display names in the app center and its update and setup notices. The app center shows package identifiers when names match and falls back to the package identifier when no display name is available.

### Optional MCP credentials

- Remote HTTP entries in the MCP catalog can support anonymous import and connection testing. Administrators can add, replace or clear an optional credential in Access settings. Changes apply to the next request.
- The gateway omits headers and query parameters that depend on a missing credential. If a catalog update changes the endpoint or credential binding and the saved credential cannot be reused, the update dialog lets administrators enter a new value or continue anonymously.
- Catalog declarations that set `credential.optional` to `true` target platform version 0.1.44 or newer.

## 简体中文

### 插件展示

- 插件库和平台应用中心显示插件图标、本地化名称与简介。已有插件可以从保存的制品补齐展示信息，无需重装。
- 管理员可编辑插件的展示名称和简介，也可恢复默认。广场引入的插件同样支持编辑，换版和广场更新保留已保存的覆盖。分组插件设置统一使用展示名称，并保留 npm 包名供核对。
- 成员应用中心的插件列表、更新和设置提示优先使用展示名称。同名时显示 npm 包名以便区分，缺少展示名称时用包名兜底。

### MCP 可选凭据

- MCP 广场的远程 HTTP 服务可支持匿名引入和连接测试。管理员可在接入配置补填、更换或清空可选凭据，保存后对下一次请求生效。
- 网关省略引用空凭据的整条请求头或查询参数。广场更新因地址或凭据绑定变化无法复用旧凭据时，管理员可在更新抽屉重新填写，或留空继续匿名使用。
- 将 `credential.optional` 声明为 `true` 的条目面向 0.1.44 及以上平台版本。
