### Scope and seams

The administrator market includes Amap and 12306 only. Bocha, GitHub,
Playwright and Kuaidi100 preset development and dedicated acceptance are deferred.
Real third-party read-only calls are distinct from controlled timeout, crash,
model and failed-update fixtures. Tests exercise installed CLI composition where
explicitly configured; source-composed regressions must be labelled separately.

The upgrade baseline is the published stable 0.1.12 release. Its private offline
handoff retains the original v0.1.12-rc.1 manifest tag and byte-identical archives;
formal release metadata and full hashes establish the stable baseline identity.
Retaining a previous successful version does not promise arbitrary downgrades.

### Installed native qualification

Eight files / eight cases passed in 794.77 seconds using the exact installed
platform and DSH image. Two members queried real Amap weather and 12306 trains,
then resumed their original sessions after actual idle reclamation. Concurrent
protocol sessions remained separate; a cross-member session request returned 404.
The discovered catalogs contained 15 Amap and 8 12306 tools.

A controlled silent call completed after 65.556 seconds. A dynamically configured
two-second deadline failed at 2.715 seconds with a timeout audit. Process exit
failed the unknown-result call; the new process had no pending/replayed call.
Credential rotation and revocation checks passed. A persisted prior-preset fixture
verified failed-update continuity and successful switching while retaining
credentials, management settings and member selections. This is not an upgrade
from a historically published market preset.

Installed terminal/streaming, native app-center category panels, original
downloads, interrupted transfers and isolated HTML passed. English desktop app-center screenshots were
inspected. Standards and Spec reviews found no unresolved issues in this slice.
Credential checks cover the inspected model requests, management/member surfaces,
audit and member-visible configuration/processes; they are not a universal leakage
proof. Clean installation is recorded separately below.

### HTTPS and document regressions

The final independent regression group passed three files / four cases in 135.09
seconds. It covers HTTP and trusted TLS preview routes, Secure cookies, native
streaming and terminal/WSS, wrong-origin/member access fences, and revocation of
the same live frame-bearing connections. Certificate verification was not bypassed.

Default Office conversion passed mixed Chinese/Latin PPTX, DOCX and XLSX. Original
hashes stayed unchanged; provider generations changed across the formal-0.1.12-image
to rc.4-image transition within the candidate platform. Four screenshots were
inspected, with readable text and font-substitution indicators. This image test
is separate from the public OS upgrade. Temporary sidebar document buttons belong
to the private test fixture; font fallback does not promise pixel-identical output.

The first regression run passed three cases and timed out in the Office member
login stage. Its failure remains retained. A minimal installed-CLI startup probe
passed; phase logging observed Podman's cold user-mapping work during login and
low free disk space. Verified unused download caches from the failed earlier
candidate were reclaimed. The diagnostic Office run passed under the original
assertions and deadlines, then the unmodified complete regression passed. No
product code, conversion deadline or assertion was changed. These observations do
not prove a unique cause or establish cold-start performance guarantees.
Independent Standards and Spec review found no remaining issues in this slice.

### Public upgrade

The public-installation upgrade acceptance case from formal 0.1.12 to rc.4
passed in 1979.354 seconds, including the negative case and before/after checks. An 8 MiB staging filesystem was rejected before interruption; the
original service PID stayed unchanged. The full transaction and cleanup then
succeeded, preserving accounts, manual MCP services, grants, member choices and
member files. Controlled MCP calls through real DSH succeeded before and after.
This run reclaimed zero bytes while protecting the retained versions; actual
historical-resource deletion is established by the dedicated storage acceptance.

English and Chinese installed market/update screenshots were inspected. The
market has exactly two entries. The update page retains a pre-existing progress
card showing its last systemctl step after success; it is not evidence of an
active operation. Independent review traced this behavior to formal 0.1.12.

### Clean Ubuntu installation

The pristine Ubuntu 24.04 amd64 acceptance case passed in 3429.35 seconds using
the public installer and exact candidate archives. The VM initially had neither
the platform nor the listed runtime prerequisites. Installation prepared them,
then administrator bootstrap, member rootless terminal and native streaming
through a controlled model passed. Starting without a shared model and adding
one through administration was verified.

Repeated installation reported no change. A deliberately corrupt archive was
rejected with exit 1; retrying the verified archive preserved configuration and
member files. A real VM reboot changed the boot ID. A fresh browser context then
verified the member file, terminal and streaming again; the independent ext4 data
mount and enabled/active service survived, with the AppArmor user-namespace
restriction still enabled. The TCG VM duration is a whole-case measurement, not a
deployment performance promise. Browser assertions passed; this clean run did
not retain screenshots and is not claimed as a separate manual visual review.

### Corrections and limitations

An earlier candidate exposed a generated installer function-name collision in
post-upgrade cleanup. Another exposed the official DSH client cancelling a silent
shared MCP call after 60 seconds, before the platform's 120-second default limit.
Both were corrected and independently reviewed. Platform request deadlines remain
authoritative; an unknown-result tool call is not automatically replayed.
Earlier failed receipts remain retained and are not counted as successful runs.

The complete quick suite passed 131 files / 405 cases after the deadline fix.
Types, lint, service and administration builds, and documentation checks passed.
Code Standards and Spec reviews have no remaining findings. Final documentation and independent evidence reviews passed.

### Validation resource retirement

The isolated upgrade and clean-install VMs were archived and shut down before
removing their unreferenced child disks. Unused native image/download caches and
temporary copied API keys were removed with ownership and reference checks.
Original candidate/formal archives, required evidence, parent disks and the
user-owned credential files were retained. The clean VM alone reclaimed
4,840,341,504 bytes. No global container/image pruning was used.
