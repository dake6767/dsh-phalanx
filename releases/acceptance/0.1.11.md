Accounts, models, groups, skill grants and member selections were retained. Home-file and Office-source hashes were unchanged. Native Linux Office conversion above uses the normal candidate configuration. ## Execution corrections and scope

An initial native Office fixture referenced a retired local image and failed before platform readiness. The fixture was corrected to the verified formal 0.1.10 baseline; the complete installed suite was rerun successfully. The first upgrade browser attempt stopped because private fixture-created member directories inherited group-writable permissions. Their modes were corrected to the product-required 0700 while preserving file hashes; no product permission guard was relaxed. Original failed receipts and corrected input hashes remain preserved.

A clean-VM preparation command initially referenced a truncated virtual disk serial and failed before formatting. The owned blank disk was positively identified before preparation continued. Interrupted archive transfers were resumed with full checksum validation. Temporary cache cleanup addressed local disk pressure without deleting source or acceptance evidence.

Independent specification and standards reviews passed for the formal native, clean-install, upgrade and post-upgrade evidence, with no remaining P0–P2 findings. Bilingual release notes and this acceptance record accompany promotion; the documentation contract is checked before their merge.

Private hosts, credentials, bootstrap links and runtime data are excluded from this public record. OpenCLI, Chrome, personal cloud browsers/VNC and the image-plugin subpath issue remain deferred. Historical local-candidate evidence is separate and does not replace these formal-candidate checks.
